Aria Home voice support — as deployed

Ember is a participant in a LiveKit room, co-located with the models. Everything she knows about a customer crosses into Google Cloud through one of three deliberately different integrations, and a human joins the same room when she hands off.

Identity

Firebase verifies the caller; Cloud Run mints the LiveKit token with the opaque uid as identity and only the account number as an attribute. Phone callers are matched on the last ten digits of caller ID.

Handoff

transfer_to_human asks the LLM for a brief (summary, next steps, mood, urgency) → desk rings for 40 s → Accept mints a specialist-* token for the same room and Ember steps back → else phone dial-out if a trunk exists → else in-room fallback.

Failure posture

Empty lookups become "I can't see that on your account"; a store outage raises and Ember escalates rather than guessing a temperature; duplicate tickets are impossible (partial unique index); cold starts avoided with min-instances.

Not in the picture

LiveKit Cloud observability (session replay, transcripts, traces), the GKE cluster that was decommissioned, and the Twilio trunk pending account upgrade.
